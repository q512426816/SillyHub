# SillyHub 平台宣传片 · 纯代码拍片

一个"宣传视频"网页：**没有任何一帧视频文件、没有任何音频文件**——影片由代码逐帧实时渲染，配乐由 WebAudio 振荡器实时合成。拍摄思路致敬 [lemomo-ai/lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)。

## V2 打开方式

直接双击 `v2/index.html`（截图在 `v2/assets/`，相对路径，离线可放）；或本地起服务：

```bash
python -m http.server 8791 --directory docs/promo
# 打开 http://127.0.0.1:8791/v2/index.html
```

## 播放器操作

- **空格 / K** 播放暂停 · **← / →** 切幕 · **M** 静音 · **F** 全屏
- 进度条点击/拖动定位（确定性渲染，seek 精确重放），悬浮显示章节名
- 画质三档：高清 / 均衡 / 省电（右下角实时帧率；卡了会自动降档）
- 片尾卡：重播全片或按幕跳转

## 修改指南（v2）

- 章节时间轴：`CHAPTERS`；每幕镜头（截图/推拉/高亮）：`SHOTS` + `HIGHLIGHTS`
- 字幕：`CAPTIONS`；配乐情绪：`CH_MOOD`（每幕和弦循环与强度）
- 截图替换：直接换 `v2/assets/` 里同名文件（1920×1080 最佳）
- 文案事实源：线上环境实拍数字（411/1066/520+ 等以采集日为准）
