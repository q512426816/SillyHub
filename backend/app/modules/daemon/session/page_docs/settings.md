## 功能定位
平台设置中心：聚合平台级全局配置的入口容器页。当前子页包括 MCP（服务器与令牌）、Skills（技能库）等；后续新增的平台级开关与偏好也在此扩展。注意区分层级：工作区级配置（工作区自己的 MCP / Skills / 智能体档案）在工作区详情页内维护，不在本页。

## 页面结构与操作
左侧子导航在各设置子页间切换；本页本身不提供独立配置项，是子页的导航容器。所有子页配置保存后即时生效，无需重启服务。

## 典型工作流
调整平台级能力（如新增一个 MCP 服务器）：进入设置 → 左导航选择对应子页（MCP）→ 在子页内完成配置（各子页细节见对应说明书）。

## 常见问题
- 找不到某个配置项：先判断它是平台级还是工作区级——工作区级配置在工作区详情页的对应 tab 里。
