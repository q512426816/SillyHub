## 平台全局地图（跨页面逻辑关系）
- **主使用动线**：工作区列表 → 建工作区并扫描（概览）→ 扫描产物喂给组件/扫描文档页 → 变更页发起规范驱动开发（提案→设计→计划）→ 变更详情里的会话工作台执行（智能体干活）→ 验证 → 归档沉淀进知识库 →（可选）发布页留档。
- **会话体系**：会话门户=全屏完整管理；右下角悬浮助手=任意页面快速入口（自动携带当前页面上下文）；工作区/变更各有范围会话页；runtimes 机器卡可钉定机器开会话。同一会话悬浮/全屏互斥切换。
- **智能体配置三层**：全局（设置：模型供应商/Skills/MCP）↔ 工作区级（工作区 tabs：档案/Skills/MCP/运行时默认）↔ 会话级（配置条热切换机器/智能体/供应商/档案）。
- **PPM 业务链**：客户 → 项目（成员/干系人）→ 项目计划 → 里程碑 → 任务计划 → 指派成员（任务执行/周计划/看板）→ 问题单跟踪风险 → 工时填报 → 工时统计复盘；项目列表「发起团队」可带项目上下文唤起 AI 团队。
- **横切能力**：审批中心（敏感操作放行）、事件（运行故障追踪）、审计与 Git 记录（追溯）、管理后台（组织/用户/角色权限）。
- **给用户的导航建议**：不知道在哪开始 → 工作台/工作区列表；想改代码 → 变更页；想问问题 → 悬浮球；想配智能体 → 档案（全局设置或工作区 tab）；管理员事项 → 管理后台。
