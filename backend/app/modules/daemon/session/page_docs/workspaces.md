## 功能定位
工作区列表——工作区是平台的核心组织单元：一个项目代码库对应一个工作区，变更（规范驱动开发）、会话、文件浏览、知识库、智能体配置都挂在它下面。

## 核心概念
- **根路径**：工作区绑定本机/挂载的真实代码目录（root_path），所有文件操作、扫描、变更都以它为基准。
- **类型**：backend-code / frontend-code / app / fullstack 等，用于档案与默认配置推导。
- **技术栈**：新建时扫描识别（语言/框架/构建命令），供智能体理解项目。

## 页面结构与操作
1. **卡片列表**：名称、类型、技术栈概览；点击进入工作区详情（开发主界面）。
2. **新建工作区**：填写根路径后触发扫描，自动识别结构与建议配置。
3. **右下角悬浮会话助手**：任何页面可唤起，携带当前页面上下文提问。

## 典型工作流
接入新项目：新建工作区填 root_path → 等扫描完成 → 进详情页跑「扫描」生成项目档案 → 从变更页发起第一次规范驱动开发。

## 常见问题
- 扫描为空：确认根路径真实存在且daemon 已挂载该目录（部署时 HOST_PROJECTS_DIR 配置范围）。
- 重复工作区：同一路径不要重复建，用详情页配置调整。
