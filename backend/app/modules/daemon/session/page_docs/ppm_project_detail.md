## 功能定位
PPM 项目详情：单个项目的工作台。围绕一个项目集中维护里程碑、任务计划、问题单（风险/缺陷跟踪）、干系人与成员，是项目全生命周期管理的落点。

## 核心概念
- **里程碑**：项目关键节点及其计划/实际时间，用于跟踪整体进度。
- **任务计划**：项目内任务的分解、排期与状态维护。
- **问题单**：项目风险与问题的登记、指派与闭环跟踪。
- **干系人与成员**：项目相关方信息与项目组成员的维护。

## 页面结构与操作
头部信息区展示项目名称、编码、状态与周期；各功能区分别维护里程碑与任务计划、登记问题单、管理干系人与成员。

## 典型工作流
项目推进：更新任务计划状态 → 里程碑临近时核对交付物 → 发现风险登记问题单并指派处理 → 需要 AI 协助时回到项目列表，行内「发起团队」带着本项目上下文唤起智能体团队会话。

## 常见问题
- 成员看不到项目：在成员管理中确认其已加入项目；项目可见性按成员关系判定。
