## 功能定位
管理平台的 LLM 模型供应商接入：配置各家模型服务（智谱 BigModel、OpenAI 兼容端点、LiteLLM 网关等）的 API 地址与密钥，供智能体档案和会话选择使用。

## 核心概念
- **供应商（Provider）**：一个模型服务的接入配置（名称、Base URL、API Key、支持的模型列表）。
- **模型角色映射**：可为供应商配置角色映射（如 one_m / fallback），会话按角色自动路由模型。
- **默认回退**：档案未指定模型时按供应商的 fallback 链降级。

## 页面结构与操作
1. 列表页查看已配置供应商与模型覆盖情况。
2. 新增/编辑供应商：填 Base URL、API Key、默认模型与角色映射。
3. 会话配置条与智能体档案可按供应商切换；token 用量环按供应商统计。

## 典型工作流
接入智谱：新增供应商（Base URL 填 open.bigmodel.cn 的 anthropic 兼容端点、填 API Key）→ 填默认模型 → 档案里选择它 → 会话即走该供应商。

## 常见问题
- 会话报模型不可用：检查供应商 Key 有效性与模型名拼写；看角色映射是否指向存在的模型。
- 切换供应商：会话配置条热切换，下一轮生效。
