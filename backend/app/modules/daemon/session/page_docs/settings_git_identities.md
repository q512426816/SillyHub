## 功能定位
管理 Git 提交身份：平台替你执行代码提交（变更执行、团队任务合并）时使用的 git 用户名/邮箱与凭证，保证仓库提交记录归属清晰、可审计。

## 核心概念
- **提交身份**：git commit 的 author 信息（用户名 + 邮箱），按平台账号配置。
- **凭证**：推送远程仓库所需的认证（HTTPS token / SSH），由平台安全存储。

## 页面结构与操作
1. 查看当前账号绑定的 git 身份。
2. 编辑用户名/邮箱；配置推送凭证。

## 典型工作流
首次使用变更执行：先在此配置与公司仓库一致的身份 → 智能体提交将以你署名。

## 常见问题
- 提交显示未知作者：检查此页身份是否配置完整。
- 推送失败：凭证过期或权限不足，更新凭证。
