## 功能定位
单个工作区的开发中枢，顶部导航组织全部能力：概览 / 变更 / 会话 / 文件 / 知识库 / 组件 / 扫描文档 / 运行时 / 智能体档案 / Skills / MCP / MCP 令牌 / 成员 / 方案文件。

## 核心概念
- **变更（Change）**：规范驱动开发单元，走 提案→需求→设计→计划→执行→验证→归档 全流程，产出物是 .sillyspec 下的四件套文档，代码改动与文档同步演进。
- **会话（Session）**：与智能体的对话，SSE 实时反馈（工具卡/Plan 确认/Bash 进度/团队任务），可绑定工作区或变更。
- **知识库**：.sillyspec/knowledge 下的经验沉淀（决策、踩坑），供人与智能体检索。

## 页面结构与操作
1. **概览**：项目档案、扫描入口（生成/刷新项目认知）、运行状态摘要。
2. **变更页**：变更列表与详情（任务卡、会话工作台、文档树）。
3. **会话页**：本工作区范围的会话门户（分组列表+面板）。
4. **文件页**：仓库浏览与查看；**知识库页**：知识条目管理。
5. **运行时/智能体档案/Skills/MCP**：工作区级智能体环境配置。
6. **成员**：成员与机器绑定（团队任务派发的基础）。

## 典型工作流
日常开发：变更页挑活跃变更 → 进入会话工作台让智能体执行任务 → 验证通过归档；或者直接悬浮球提问（自动带本工作区上下文：名称/类型/路径）。

## 常见问题
- 变更不见了：确认在「变更」tab 且未被归档（归档库在模块文档中可查）。
- 会话连不上：看运行时页机器是否在线。
