## 功能定位
管理平台的 MCP（Model Context Protocol）接入层：MCP 服务器为智能体提供外部工具能力（检索、数据库、第三方 API 等），MCP 令牌供外部服务安全回调本平台。本页是"智能体能用什么外部工具"的配置中枢。

## 核心概念
- **MCP 服务器**：一个对外提供工具/资源的服务进程，支持 stdio（本地命令拉起）与远程（URL）两类传输；智能体运行时可连接并调用其工具。
- **MCP 令牌**：平台签发的回调凭证，外部 MCP 服务用它与平台安全通信，可配置仓库/分组过滤限定作用范围。

## 页面结构与操作
1. **服务器列表**：添加/编辑服务器（名称、传输方式、启动命令或 URL、环境变量），提供「测试连接」验证可达性与协议握手。
2. **令牌管理**：创建令牌后复制分发给外部服务；可随时吊销。
3. **引用挂载**：在「智能体档案」或工作区配置中引用服务器后，该智能体的会话即可调用其工具（工具名以 mcp__ 前缀出现在会话工具卡中）。

## 典型工作流
接入一个外部检索服务：服务器页添加（远程 URL）→ 测试连接通过 → 到智能体档案勾选引用 → 在会话中让智能体检索，观察工具调用卡。

## 常见问题
- 工具不出现：检查服务器是否在线、档案/工作区是否已引用、会话是否在引用之后创建。
- 测试连接失败：确认命令路径/URL 可达、环境变量齐全；stdio 型需机器侧依赖就绪。
