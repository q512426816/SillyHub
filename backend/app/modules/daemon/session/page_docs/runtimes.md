## 功能定位
机器与运行时引擎的管理台：机器是安装了平台 daemon 的设备（开发机/服务器），运行时（Runtime）是机器上的智能体引擎（Claude Code、Codex、Cursor、Kimi、OpenClaw、OpenCode、Pi 等）。所有会话最终都派发到某台机器的某个运行时上执行。

## 核心概念
- **daemon**：机器侧常驻进程，负责注册、心跳、领取任务、运行智能体引擎并回传实时事件（SSE 流的源头）。
- **在线状态**：心跳超时的机器自动转离线，其运行时不可派发新会话；已运行会话进入恢复流程。
- **自更新**：daemon 与机器支持平台分发的一键升级（/daemon/install.sh 安装脚本）。

## 页面结构与操作
1. **机器列表**：查看每台机器的在线状态、别名、心跳时间与全部运行时引擎。
2. **运行时管理**：按引擎禁用/启用（禁用后不再派发）、触发自更新。
3. **发起会话**：机器卡上的会话入口直接与该机的引擎对话（钉定机器，不自动换机）。

## 典型工作流
新机器接入：在目标机执行平台提供的安装命令 → 机器自动注册并心跳在线 → 此处确认运行时引擎在线 → 会话创建时即可选择它。

## 常见问题
- 机器离线：检查目标机 daemon 进程与网络；离线机器上的会话会在恢复后继续。
- 引擎缺失：在机器上安装对应 CLI 后运行时会自动注册。
