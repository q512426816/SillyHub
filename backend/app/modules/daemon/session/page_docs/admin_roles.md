## 功能定位
管理后台的角色权限：角色是菜单可见性与操作权限点的集合，授予用户后生效，决定"谁能看到什么、能做什么"。

## 核心概念
- **菜单权限**：控制左侧导航与页面入口的可见性。
- **操作权限**：控制具体动作（创建/编辑/删除/审批等）的允许。

## 页面结构与操作
1. 角色列表：新建/复制/编辑角色。
2. 权限矩阵：勾选菜单与操作权限点。
3. 在用户管理把角色授予用户（可多角色叠加）。

## 典型工作流
建「项目管理员」角色：勾选 PPM 相关菜单与操作 → 授予对应成员。

## 常见问题
- 改了权限不生效：用户需重新登录刷新令牌；平台级页面（会话等）默认登录可见。
