## 功能定位
单个变更的详情页：变更的指挥中枢——四件套文档树、任务卡清单、执行会话工作台与验证结果汇集于此。

## 页面结构与操作
1. 文档区：proposal/requirements/design/plan/tasks 的查看与演进。
2. 任务卡：按 wave 分组的执行单元，点开看实现/验收约束。
3. 会话工作台入口：发起/继续该变更的执行会话（自动携带变更上下文前导）。
4. 验证结果：对照设计与模块文档的验收记录。

## 典型工作流
日常开发主路径：本页选任务 → 会话里让智能体执行 → 验证 → 勾任务 → 全绿归档。

## 常见问题
- 文档与代码不一致：以最新文档为准，发现偏差及时修正（规范铁律）。
