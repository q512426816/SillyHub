## 功能定位
智能体档案——定义一个智能体"是谁、用什么大脑、有什么工具"：系统提示词、模型与供应商、MCP 服务器与 Skills 挂载。会话创建时选档案即按其配置运行，运行中可热切换。

## 核心概念
- **系统提示词**：智能体的角色与行为约束（身份、风格、边界）。
- **供应商/模型**：LLM 请求路由（平台 LLM 供应商管理 + 本机默认），决定实际调用的模型。
- **MCP/Skills 挂载**：档案级工具集，决定会话中可用的外部工具与技能。

## 页面结构与操作
1. **档案列表**：新建/复制/编辑档案。
2. **编辑表单**：系统提示词（支持变量）、默认供应商与模型、MCP 服务器多选、Skills 多选。
3. **会话中使用**：创建会话时选择档案；配置条可中途切换（下一轮生效，快照留存）。

## 典型工作流
打造"项目助理"：新建档案 → 写系统提示词（资深全栈工程师，遵循仓库规范）→ 挂载工作区相关 MCP 与 Skills → 会话创建时选它。

## 常见问题
- 切换不生效：切换在下一轮对话生效，当前轮仍用旧配置。
- 工具缺失：检查档案的 MCP 挂载与对应服务器在线状态。
