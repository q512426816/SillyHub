## 功能定位
自定义技能（Skills）管理：技能是可复用的提示词/流程包（Markdown 规范），挂载给智能体档案后在会话中按名调用，相当于给智能体预置的"操作手册"。

## 核心概念
- **技能内容**：一段结构化的指令文档（目标、步骤、约束、输出格式）。
- **挂载引用**：档案勾选技能后，会话中智能体按需读取并遵循执行。

## 页面结构与操作
1. 列表页新建/编辑技能（名称 + Markdown 内容）。
2. 在智能体档案的 Skills 配置中勾选引用。

## 典型工作流
沉淀团队规范：把"发布检查清单"写成技能 → 挂到运维档案 → 会话中说"按发布技能走一遍"。

## 常见问题
- 技能未生效：确认档案已挂载且会话在挂载后创建/切换过配置。
