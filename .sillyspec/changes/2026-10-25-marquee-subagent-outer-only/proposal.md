# 提案书（Proposal）— 2026-10-25-marquee-subagent-outer-only

## 动机

任务原话转写：跑马灯外部只显示子代理容器条目

动机：子代理内部消息目前也进入外部跑马灯刷屏；用户希望外部只显示子代理名称+运行状态+时间，内部消息留在对话流的子代理卡片内展示。

成功标准：
- 外部跑马灯不再收集子代理内部消息：tool 带 children 与 subagent_stub 分支都不递归 children，仅保留容器条目
- 子代理容器条目显示名称、运行状态（转圈）与时间：运行中显示走秒计时（优先用段 startedAt，缺省用客户端首次观察起点），完成后显示总耗时
- 工具条目同样获得运行中走秒计时；无起点数据时只转圈不显示时间
- 子代理内部消息继续在对话流子代理卡片内展示（现有行为不变）
- 更新子代理递归相关测试并新增走秒计时用例，全部通过；lint与typecheck通过
- 原型核验：外部只出现子代理容器条目，内部工具不出现
