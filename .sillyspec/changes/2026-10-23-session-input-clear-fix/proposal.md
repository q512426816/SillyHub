# 提案书（Proposal）— 2026-10-23-session-input-clear-fix

## 动机

任务原话转写：会话输入框发送即清与草稿隔离修复

动机与背景：用户反馈会话页输入框三类体验问题——①在其他会话/预会话填写过 AAA，新建会话仍显示 AAA；②发送后内容不立即消失，卡在输入框等网络响应（排队感）；③发送在途切换会话后切回，已发送内容仍残留输入框。根因：清空输入走 setState→effect 写草稿链路，组件卸载后清理不执行（预会话草稿键残留）；预会话草稿跨「重新新建」回读；onSendSettled 等响应成功才清文本。

成功标准：
- 点击/回车发送后输入框文本立即清空，不等网络响应
- 发送失败（网络错误/后端拒绝）时输入文本恢复到输入框可重试，附件 chips 全程保留
- 发送受理即同步清 localStorage 草稿键（含预会话 __pre__:scope 键），切换会话/组件卸载后草稿不残留已发送内容
- 新建会话（预会话态）输入框恒空白：不回读旧草稿，且每次重新进入预会话（同机器同引擎）输入框重置（key 加 nonce 强制重挂载）
- 群聊输入区同款：发送立即清空 + 失败恢复
- 既有会话草稿持久化（真会话切换/刷新恢复草稿）不回归
