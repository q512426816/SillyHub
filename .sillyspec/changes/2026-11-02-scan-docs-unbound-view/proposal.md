# 提案书（Proposal）— 2026-11-02-scan-docs-unbound-view

## 动机

任务原话转写：扫描文档页无绑定也可浏览服务端存量数据

动机：扫描文档的列表/详情/搜索/统计/重新扫描在后端均为纯服务端读取（scan_documents 表 + 服务端 spec 镜像；reparse 权限为 WORKSPACE_WRITE，全程不触 daemon），但前端页面要求当前账号有 daemon 绑定才拉列表，无绑定账号整页只见 DaemonRequiredNotice 引导页，服务端已有数据不可见。工作区镜像由成员 daemon 推送保持新鲜（60-90s 周期），知识库列表页已是零绑定门槛先例，扫描文档页应同口径。

成功标准：
