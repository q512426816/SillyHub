位于「首次安装 daemon（新机器）」折叠块下方，同一视觉层级；本命令三平台通用，无 OS 切换按钮
⌨irm https://hub.example.com/daemon/install.ps1 | iex

安装完成并至少成功启动过一次后，想让 daemon 随开机自动运行，在终端执行：

⌨sillyhub-daemon autostart enable --server https://hub.example.com --api-key <你的 API Key>

⚠️ 自启动场景请用 API Key（长效），用登录 Token 会过期失效。在哪里获取 API Key？→ 个人设置 · API Keys。

常见管理命令：sillyhub-daemon autostart status 查看注册状态 · sillyhub-daemon autostart disable 取消自启（不会停止正在运行的 daemon）。

说明：命令三平台相同（内部自动按 Windows 计划任务 / macOS launchd / Linux systemd 处理），因此不需要 InstallDaemonBlock 那样的 OS 切换按钮——这是与安装块的关键差异。
