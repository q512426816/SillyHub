# 提案书（Proposal）— 2026-10-23-session-first-load-ux

## 动机

任务原话转写：会话首屏加载提速：补拉链不阻塞渲染+加载骨架屏

进入会话面板时轮次列表出现慢且加载中无动态指示。慢的根因：首屏自适应补拉链（底窗→probe→锚点轮直达→并行补8轮）串行阻塞首次渲染，大会话多等数秒。无指示根因：历史在飞时时间线渲染静态空态文案（如「XX 已就绪」），用户以为页面空白卡死。

成功标准：
- 历史加载在飞期间，时间线区域显示轮次骨架屏（动态加载指示），不再显示静态空态文案或空白
- 首屏轮次内容在底窗日志（400行）到达后立即渲染，不等 buildInitialWindow 补拉链完成；补拉结果到达后增量合并进时间线，翻页游标与「加载更早」语义不回退
- 真无轮次的空会话仍显示原空态文案，不误显骨架屏
- 既有测试不回归，新增加载态与分阶段渲染行为有测试覆盖
