# 需求文档（Requirements）— 会话子代理三分栏展示

> 决策追踪：FR-01/FR-03 覆盖 D-001@V1；FR-02/FR-04 覆盖 D-002@V1；FR-01/FR-05 覆盖 D-003@V1。全部当前版本决策均有对应需求，无剩余风险。

## FR-01 右栏单槽位互斥
- 会话页最右栏为单槽位：文件预览 或 子代理详情，同一时刻至多一个。
- 点击子代理卡片 → 子代理详情占据右栏（已打开的文件预览被关闭）。
- 点击工作区文件 → 文件预览占据右栏（已打开的子代理详情被关闭）。
- 关闭（✕）或会话切换 → 右栏清空，中栏回宽。

## FR-02 中栏子代理紧凑卡片
- 中栏（对话视图与进度视图一致）中，子代理只展示：状态点（运行中脉冲/成功/失败/已停止）、🤖、名称、子代理类型标签、（后台任务）状态徽标、运行时长。
- 不展示子代理内部细节（文本/工具调用等不再内嵌）。
- 卡片可点击，点击后右栏打开该子代理详情；当前打开的卡片有高亮态。
- 运行时长：后台任务终态用服务端权威 taskElapsedMs，运行中本地走秒；前台子代理用 startedAt/endedAt。

## FR-03 右栏子代理详情面板
- 面板内容与格式和主会话一致：完整渲染子代理 children 段时间线（text/thinking/tool 展开区/file/stderr），复用 SegmentView 组件族。
- 面板数据实时（SSE 增量即刷新），不做快照。
- 面板**无输入框**，不支持继续对话。
- 头部：✕ 关闭、🤖、名称、类型、状态徽标、运行时长。
- 嵌套子代理（depth>1）在面板内仍是紧凑卡片，点击切换到该嵌套子代理。
- 段 id 失效（会话重装配后不存在）→ 面板自动关闭。

## FR-04 对话视图可见性
- 默认对话视图不再过滤子代理容器段：子代理以紧凑卡片出现在对话流中。
- 其余段（thinking/tool/stderr/preamble）在对话视图保持过滤不变。

## FR-05 兼容与回归
- SessionPanel 新 props 全部可选；未传入时（dialog 弹窗/悬浮宿主等旧消费方）行为与现状完全一致（子代理内联展开回退）。
- 右栏宽度拖拽、localStorage 记忆与文件预览共用同一状态和键。
- Windows/Linux/macOS 兼容（纯前端逻辑，无平台相关代码）。

## 验收标准
1. 对话/进度两视图中子代理均为紧凑卡片，无内联细节。
2. 点卡片 → 右栏完整时间线，格式与主会话相同，无输入框。
3. 子代理 ↔ 文件预览互斥，严格按最后触发覆盖。
4. 会话切换后右栏不残留旧会话的子代理面板。
5. 对话框模式 SessionPanel 行为零变化。
6. 相关新旧单测全绿；`pnpm lint`/`pnpm test`（相关文件）通过。
