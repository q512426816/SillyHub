# proposal.md — 2026-09-08-session-turn-nav

## 一句话

/sessions 智能体会话页新增「轮次导航」左栏（参考 ZCode）：按轮列出用户提问+助手正文摘要，点击跳转定位到对应轮次；覆盖全部历史轮次（含未加载），高轮次会话可快速回顾"之前问了什么、做了什么"。

## 背景与问题

- 用户反馈：会话轮次过高时，无法快速了解之前在会话里问了什么、做了什么；现有手段只有手动滚动（历史分窗加载，初始仅最近 100 条日志）或会话内搜索（搜索结果浮层只展示、不能跳转定位）。
- 参考 ZCode 会话：聊天左侧常驻目录（历史用户提问+助手正文摘要），点击直接跳到对应位置。

## 目标

1. 会话面板聊天区左侧新增常驻「轮次导航」栏（桌面），可折叠；移动端/悬浮窗收进 ⋯ 菜单以抽屉呈现（D-001）。
2. 目录覆盖全部历史轮次：已加载轮次直接跳转；未加载轮次由 `GET /sessions/{id}/runs` 补全条目，点击自动连续加载历史日志后定位（D-002）。
3. 条目两段式：用户提问一行摘要 + 助手正文两行摘要（D-003）；不点过去即可回顾。
4. 跳转后目标轮短暂高亮 + 目录与聊天滚动位置双向联动（当前视口轮次高亮）。

## 不在范围内 / Non-Goals

- 不新增后端端点（方案 C 拒绝，D-004）；v1 不给 runs 响应加 prompt_preview 字段（D-005 记录为可选增强，待用户原型确认时定夺）。
- 不改会话列表（左 320px 跨会话列表）与群聊面板。
- 不做目录内搜索/过滤（会话内搜索已有，正交）。
- 不做虚拟滚动改造（TurnTimeline 现状保留，目录条目量级 = 轮次数，普通渲染可承受）。
- 不改 dialog 模式（runtimes 弹窗会话）的常驻布局——dialog 宿主 v1 不挂左栏，仅数据锚点（data-turn-key）随之具备。

## 方案摘要

方案 A（前端拼装，零后端改动）：目录数据 = `displayTurns`（已加载轮次，含 prompt 与正文段）+ `listSessionRuns`（全量轮次元数据）合并；跳转经 `TurnRow` 新增 `data-turn-key` 锚点 + `scrollIntoView`，未加载目标先循环触发既有触顶翻页链（`handleLoadEarlierRef`）加载到命中再定位。
