# 视觉证据（visual-evidence）— 2026-10-15-graph-type-cluster

## 证据形态说明

本变更改的是**力场布局的物理组成**（canvas 绘制代码零改动：色板/半径/标签/边线/交互绘制全部未触碰），视觉变化 = 节点位置分布。因此视觉证据取**确定性几何断言**而非截图对照：

- 单测聚簇双断言（graph-canvas.test.ts「聚簇双断言」用例）：18 节点 3 类型交错网格快进 4000 步后，类内最大离质心距离 < 150、异类质心两两间距 > 150 且间距 > 类内径——即「同类型一坨、不同类型分开」的几何事实被钉死，力场为确定性系统（同输入同输出，无随机面）。
- 校准数据（一次性 JS 复刻脚本实测）：pull=0.02 时类内半径 ≈47.8px、类间质心距 ≈163.3px、尾段每帧位移 ≈0.001（完全收敛）。
- 对照基准说明：归档原型 prototype-knowledge-graph.html 的力场无类型内聚（本变更在设计记录中如实声明为原型之后唯一力组成增补，非降级——用户需求即偏离原型的混色形态）。

## 实页确认

画布为动态力场 + 需 daemon 图数据，未截实页图；用户下次打开知识图谱页执行任意切片查询（如 neighbors 预置胶囊）即为实页验收：同类型节点应聚为色块、跨类型关联呈桥接边。若聚簇观感过紧/过松，调 `TYPE_COHESION_PULL`（0.012～0.035 均为收敛稳定带，校准数据见 design.md 风险节）。
