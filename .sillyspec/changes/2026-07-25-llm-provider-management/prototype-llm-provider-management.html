生效链路（设计要点）
你 在网页配好供应商（API Key 加密存后端） → 跑 Claude Code 时，后端把你的默认供应商随任务包(lease)下发 → daemon 把配置翻译成环境变量：ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN / ANTHROPIC_DEFAULT_SONNET_MODEL 等 → Claude Code 用你指定的供应商和模型映射跑。

• 配置跟随账号，所有工作空间通用。
• 没配供应商时，daemon 用本机原有配置兜底（不影响现有使用）。
• 切换默认 = 一键，立即对后续任务生效。
• 加 Codex/Gemini：后端表 agent 种类加值 + daemon 加注入器，协议/表结构不变。
• 不支持（反代相关）：自定义 User-Agent / Header 覆盖 / Body 覆盖 / API 格式转换 —— 这些需要本地反代拦截，daemon 是直接启动设环境变量、不走反代。
