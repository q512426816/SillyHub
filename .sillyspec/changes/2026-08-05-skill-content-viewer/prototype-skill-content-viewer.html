sillyspec-archive 系统自带
用于归档已验证完成的变更。执行模块影响分析 + 同步模块文档 + 移动到 archive 目录 + 更新 ROADMAP。

何时使用

  • 用户说"归档、archive、收尾这个变更"
  • verify 已通过，把变更包归档沉淀
  • 5 步：任务完成度检查 → 模块影响分析 → 同步模块文档 → 确认归档 → 更新路线图

步骤生命周期（所有阶段通用）

sillyspec archive 是 sillyspec run archive 的顶层别名，两者等价。
sillyspec run archive                          # 输出当前步骤 prompt
sillyspec run archive --done --output "摘要"   # 完成当前步骤
sillyspec run archive --status                 # 查看阶段进度
sillyspec run archive --reset                  # 重置阶段（从头开始）

通用参数

参数说明
--change <名>指定变更名（多活跃变更必填）
--spec-dir <path>指定规范目录
--json输出 JSON（程序化读取）

归档前硬校验

CLI 移动目录前会校验 plan.md 存在——缺失则 exit(1) 阻断。移动后校验 design.md / module-impact.md（缺失只告警）。
