# 提案书（Proposal）— 2026-10-22-protect-cjk-source

## 动机

任务原话转写：生产复现：英文思考内容里夹中文引用（如 "合并键应该是工区不是厂房"），opus-mt en→zh 模型收到源端中文 token 时 tokenizer 产出 <unk>、束搜索陷入重复，译文出现大量反斜杠乱码并丢失语义；复现脚本输出 has_backslash_runs=True

成功标准：
- 源端口语中文片段（汉字与中文/全角标点）必须作为保护段原样保留，禁止进入送翻文本
- 含中文引用的英文思考内容翻译后禁止出现反斜杠连续乱码，中文引用必须原样保留
- 纯英文内容翻译行为不变（保护段/URL 既有语义不回退）
- 相关测试通过：后端 translate 模块测试（含新增中文片段保护用例）
