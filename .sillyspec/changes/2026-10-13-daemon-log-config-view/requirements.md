# 需求规格（Requirements）

## 角色

| 角色 | 说明 |
|---|---|
| 平台管理员（管理员用户） | /runtimes 机器卡的可见与操作者；本变更两个端点沿用机器管理面 RuntimeAdminUser 鉴权 |
| daemon（本地守护进程） | 被查看方；提供两个只读 RPC（daemon_log_tail / daemon_config_get），路径与脱敏在其侧权威解析 |
| backend | 转发方；machine 级端点 → WS RPC，负责错误映射（504/422/502） |

## 功能需求

### FR-01: 日志尾部查看

Given 一台在线且已升级的 daemon 机器
When 管理员在机器卡点击「日志」并选择行数（100/500/2000，默认 500）
Then 弹窗展示 daemon.log 尾部对应行数内容 + 文件路径/大小/最后修改时间；超出尾部字节上限（256KB）时提示截断；点击「刷新」重新拉取

### FR-02: 日志下载

Given 日志 Tab 已展示尾部内容
When 点击「下载日志片段」
Then 浏览器下载与当前展示一致的行内容（文件名含机器名与 tail 标识）

### FR-03: 配置查看（默认脱敏）

Given 一台在线且已升级的 daemon 机器
When 管理员在机器卡点击「配置」
Then 弹窗展示当前生效配置 JSON；`token`/`api_key` 等敏感字段为掩码形式（前4位+***+后4位，不足8位整值掩码），并标注被掩码字段清单

### FR-04: 配置明文按需切换

Given 配置 Tab 处于掩码态
When 点击「显示明文」
Then 向 daemon 发起 reveal=true 的二次拉取并显示明文；再次点击恢复掩码态（重新拉取掩码态）

### FR-05: 配置下载（恒脱敏）

Given 配置 Tab 可见（掩码或明文态）
When 点击「下载配置」
Then 下载恒脱敏 JSON 文件（无论页面处于掩码态还是明文态，敏感字段均为掩码，D-007）；按钮旁标注「下载内容始终脱敏」

### FR-06: 版本过旧提示

Given 目标机器 daemon 未升级（未注册新 RPC）
When 打开日志/配置 Tab
Then 展示 warning 提示条「daemon 版本过旧，请先升级」，引导到机器卡「升级 daemon」，不弹技术错误

### FR-07: 日志不存在提示

Given 目标机器 daemon 前台（TTY）运行，未落盘 daemon.log
When 打开日志 Tab
Then 展示提示条「daemon.log 不存在——前台运行不落盘日志」，说明后台运行/CLI 两种替代查看方式

### FR-08: 离线禁用

Given 机器离线（无 WS 连接）
When 查看机器卡
Then 「日志」「配置」按钮禁用并给出离线 tooltip；若拉取过程中离线则展示错误条

## 非功能需求

- 兼容性：老 daemon 未升级时平台其余功能不受影响（未知 RPC 仅在显式点击时触发）；无新配置项、不改现有 API/表结构/心跳协议；Windows/Linux/macOS 三平台路径处理一致（路径全部由 daemon 侧解析，前端/后端不拼路径）。
- 安全：默认请求路径不传输明文凭据；掩码字段清单与 DaemonConfig 定义同处维护；全链路只读，无配置写回。
- 性能：日志读取分块（64KB）尾部扫描，不全量加载；RPC 行数上限 5000；backend RPC 超时 30s。
- 可用性：弹窗打开时日志区自动滚动到底部（看最新日志）；错误提示全中文、带下一步指引。
