降级/异常态（同一页面内的提示区域）

① daemon 离线 → 🟠「本机守护进程离线，无法浏览工作区文件。请启动 daemon 后刷新。」
② 未绑定 → ⚪「当前账号未绑定本机工作区，请先到「成员」页完成绑定。」
③ daemon 版本过低 → 🟡「本机 daemon 版本过旧，不支持文件浏览，请升级 daemon。」
④ 大文件/二进制 → 预览区显示元信息卡片（大小/类型/修改时间）+ 下载按钮，不渲染内容。
数据链路： 浏览器 ──JWT──► backend GET /api/workspaces/{id}/explorer/tree|file|download │ ① 鉴权 WORKSPACE_READ ② 查当前用户绑定(workspace_id,user_id)→daemon_id+root_path │ ③ 相对路径 containment 预检（按 root 形态分发 Win/POSIX 语义） ▼ WS RPC（tree/file 30s，search/download 60s） daemon explorer_list_dir / explorer_read_file / explorer_search │ ④ 主防线：realpath 落点必须在 root 内 + allowed_roots 双校验 │ ⑤ 搜索时跳过 node_modules/.git/dist…（目录树全量展示不排除） ▼ 宿主机工作区磁盘（只读 readdir/read，≤10MB 截断）
