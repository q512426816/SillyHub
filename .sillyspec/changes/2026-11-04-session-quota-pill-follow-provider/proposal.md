# 提案书（Proposal）— 2026-11-04-session-quota-pill-follow-provider

## 动机

任务原话转写：会话页底部「模型剩余额度」胶囊应按当前选中的供应商展示：现在胶囊面取聚合排序第一家的数据，切换供应商（含配置条暂存未发送）后仍显示别家额度；选中 OpenCode Go 等不支持额度查询的供应商时，直接用其他可查供应商的数据顶替，误导用户。

成功标准：
- 配置条切换供应商（暂存未发送）后，底部额度胶囊立即按新供应商展示，不再显示其他供应商的数据
- 选中供应商不支持额度查询时，胶囊明确显示该供应商名与「暂不支持额度查询」，不渲染其他家额度数据
- 选中供应商可查但本次无数据时，胶囊显示该供应商名与「额度暂无数据」
- 点击胶囊浮层仍可查看其余可查供应商的额度，且选中供应商置顶
- 未指定供应商（本机默认）时保持原有全部可查供应商聚合展示行为
- 相关单测更新并通过，lint 通过
