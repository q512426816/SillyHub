④ 注入诊断面板（抽屉）D-011FR-08

点右上"注入诊断"展开。五项诊断在 backend 渲染时预检（不是 daemon 事后上报），所以看到的就是将要发生的。

遮蔽
platform_name_shadow · playwrightworkspace「multi-agent-platform」的 .mcp.json 里也有同名 server —— 三层合并时 workspace 优先，平台库这份配置实际没生效。建议改名或删 workspace 里那份。
白名单
workspace_blocked_by_whitelist · internal-toolsworkspace「内部工具」的 .mcp.json 里 server「internal-tools」不在白名单 mcp.whitelist 内，注入时会被剔除。
解密
decrypt_failed ·（示例）legacy-db密钥轮换后失配：该 server 渲染时降级为无 secret 形态并跳过注入。去编辑页重新保存密钥即可。
死角
bound_but_disabled ·（示例）fetch有 platform 绑定但 enabled=false —— 配置了却没生效，确认是否有意为之。
类型
invalid_type_defensive ·（示例）—防御项：写路径已限制 stdio，若历史数据混入 http/sse 会在 platform 位整包回落，此项应为空。
