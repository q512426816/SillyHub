# 需求规格（Requirements）— 2026-10-22-session-composer-slim

## 功能需求

### FR-01: 排队消息等纯文本展示中的附件/工作区引用标记统一简化为简洁文件名标签，不再露出 uuid

- 任何以纯文本展示消息正文的界面（排队消息条、定时消息条、复制结果）**必须**先把附件标记行与行内引用标记转换为可读文本：附件显示为「📎 文件名」、文件/目录显示为「📄/📁 名称」、代码段显示为「🧾 名称:起-止」；**禁止**向用户展示 `[附件引用:<uuid>|…]`、`[附件:<uuid>|…]` 等原始协议长串。
- 消息气泡内既有的可点击引用标签行为**必须**保持不变（仍可点击预览）。
- 发送给后端/daemon 的正文协议**禁止**在本变更内改动——本次只收敛展示层。

#### 场景：排队消息含附件引用

- Given 用户带附件发送一条消息，当前轮运行中该消息进入排队
- When 排队条渲染该条目的折叠摘要或展开正文
- Then 显示「📎 文件名」等简洁文本，不出现 uuid；折叠态附件数量标识照旧

#### 场景：复制用户消息

- Given 历史用户消息正文含行内附件/工作区引用
- When 用户点击气泡的复制按钮
- Then 剪贴板文本为简化后的可读文本，不含协议标记

### FR-02: 配置条移除中断自动续跑开关与运行中提示，入口合并进输入框左侧 + 号菜单并可切换

- 会话配置条（`SessionConfigBar`）**必须**移除「中断自动续跑」开关、其说明文字以及「运行中切换将于本轮结束后生效」常驻提示，不再占用底部行宽。
- 输入框左侧 + 号功能菜单**必须**新增「中断自动续跑」项：展示当前开关状态，点击即切换并复用既有 PATCH 会话配置链路；禁用态（会话结束/机器离线）**必须**禁用并给出原因。
- 仅有会话级续跑状态时渲染该项（预会话/无会话状态不渲染）；桌面与移动端**必须**都可达。

#### 场景：在 + 菜单切换续跑

- Given 真实会话、机器在线
- When 用户打开 + 菜单并点击「中断自动续跑」
- Then 菜单项状态立即翻转，并向父层发出反向开关请求；底部配置条不再出现该开关

#### 场景：终态禁用

- Given 会话已结束或机器离线
- When 用户打开 + 菜单
- Then 「中断自动续跑」项为禁用态，悬停显示原因，点击不触发请求

### FR-03: 最右侧模型额度改为紧凑动态小图标，只显示最低剩余百分比，点击弹出完整明细

- 配置条最右侧额度控件**必须**由长文本胶囊改为紧凑图标按钮：仅显示「度量图标 + 当前会话所配供应商的第一个额度窗口百分比」（D-001 对标题锚中数值口径的用户修订），百分比颜色按既有阈值（≤20% 红 / ≤50% 黄）动态变化；当前会话供应商不可查或无百分比窗口时**必须**回退到排序第一家的首窗口；纯余额类无百分比时**可以**只显示图标。
- 模型名、窗口标签、重置时间、「等 N 家」**必须**收进点击弹出的明细浮层（浮层内容维持现有供应商/窗口/重置时间结构）。
- 悬浮满 2 秒立即刷新、5 分钟轮询、弱依赖静默降级等既有数据行为**必须**保持不变。

#### 场景：多供应商多窗口

- Given 当前会话供应商为智谱，5 小时窗剩 100%、周限额剩 57%，另有 1 家供应商可查
- When 配置条行尾渲染
- Then 图标旁只显示「100%」（当前会话供应商首窗口），不显示模型名/重置时间/等 N 家；点击后浮层列出全部明细

#### 场景：低额度变色

- Given 当前会话供应商首窗口剩余百分比为 15%
- When 渲染额度图标
- Then 百分比呈红色（error 语义色），图标整体仍为紧凑尺寸

### FR-04: 桌面与移动端行为一致，附件预览/排队/发送等既有功能不回归

- 上述三项改动在 desktop 与 mobile 两种形态下**必须**均可用：移动端续跑入口经 + 菜单可达，额度图标仍为紧凑形态并保留点击明细。
- 既有附件上传、行内引用点击预览、排队/编辑/重试、发送与中断等交互**必须**不回归；发送正文协议与后端接口**禁止**变化。

#### 场景：移动端

- Given 移动端窄屏打开真实会话
- When 打开 + 菜单并查看配置条行尾
- Then 续跑开关可在菜单中切换；额度图标不撑破配置行且可点击查看明细

### FR-05: 相关单测与 lint 通过

- 本次触及文件的单测**必须**全部通过，且相关断言随新呈现形态更新；前端 lint **必须**通过。
- 全量测试**禁止**在本地执行（按项目规则留给 CI），只跑与改动相关的测试文件。

#### 场景：交付核验

- Given 完成代码与测试修改
- When 运行相关 Vitest 用例与 lint
- Then 全部通过，无新增告警
