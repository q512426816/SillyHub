# 提案书（Proposal）— 2026-10-25-marquee-awaiting-real-data

## 动机

任务原话转写：跑马灯等待条目接入真实计时与token

动机：用户反馈等待模型响应的计时是页面本地掐表不真实（刷新重置）；且 daemon 的 tokens 事件已实时推本轮累计 token，应在等待条目回显。

成功标准：
- 等待起点改用最后事件的服务端时间戳（日志/工具段的 endedAt/startedAt/ts 最大值），刷新或中途打开页面后等待时长继续累计不重置；无服务端时间时回退客户端起点
- 等待条目回显本轮累计 token（↑输入 ↓输出，来自 tokens 事件实时更新的轮级数据）；无 token 数据不显示该段
- 会话整页与弹窗两模式均接入；子代理卡片内嵌条不显示轮级 token（作用域是主轮）
- 相关测试更新与新增；全部通过；lint与typecheck通过
