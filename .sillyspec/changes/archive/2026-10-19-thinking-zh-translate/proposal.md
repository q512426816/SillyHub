# 提案书（Proposal）— 2026-10-19-thinking-zh-translate

## 动机

任务原话转写：思考内容离线翻译为中文展示

动机：平台会话中 agent 思考内容常为英文，用户看不懂。集成离线翻译能力（不依赖云翻译 API），默认将思考内容译成中文展示，同时控制性能开销。

成功标准：
- 会话思考内容默认显示中文译文，可一键切回原文；折叠摘要流式结束后亦译为中文
- 翻译为本地离线推理（后端 CTranslate2 + opus-mt-en-zh int8 量化模型，首用自动下载、可配置本地目录），全程无外部云翻译 API 调用
- 性能可控：按需触发（用户展开或流式结束后）、文本分块并发、译文缓存（内存 LRU + Redis），不阻塞会话流式渲染；模型不可用时优雅降级显示原文
- 覆盖三条思考渲染路径：daemon 会话面板时间线、AgentLogViewer、agent-logs 回放卡
