# 提案书（Proposal）— 2026-10-14-logout-localstorage-user-data-cleanup

## 动机

任务原话转写：动机：登出换账号后 localStorage 里按 sessionId/groupId 索引的用户数据（会话草稿、群聊草稿、未读锚点、活性状态等）不清——A 用户的草稿/未读残留可被 B 用户看到（出处 archive/2026-10-14-logout-full-reload-clear-cache review.json P3）。
成功标准：
- 全仓清查 localStorage 键并区分用户域（按 sessionId/groupId/会话内容索引）与设备级偏好（主题/输入框高度/浮球位置等），清单落 design
- 主动登出（桌面+移动）在整页跳转前统一清理全部用户域键，设备级偏好保留
- 清理逻辑集中一处注册表实现，新增用户域键只改注册表不散落
- 补清理行为测试：登出后用户域键被清、设备级键保留
- 现有相关测试不回归
