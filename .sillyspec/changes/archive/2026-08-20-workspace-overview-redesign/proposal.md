# 提案书（Proposal）— 工作区详情页工作台式重构

## 动机

工作区详情页（/workspaces/[id]）九大块纵向平铺无层次、快速入口是文本按钮堆、头部单薄、低频配置拉长页面。用户在 AI-Native 主题落地后要求该页整体重构，并确认方向为工作台式四段布局。

## 关键问题

1. 信息重要度不分区：统计卡埋中部、高频基本信息与低频配置同级。
2. 快速入口 6 项挤成文本链接堆，与主题系统的图标卡片语言不符。
3. 头部只有一行 PageHeader，无横幅无操作锚点。
4. 543 行单文件页面难维护，展示与状态逻辑耦合。

## 变更范围

- 四段式重排：头部横幅（渐变+操作组）→ 统计卡行（四卡图标化，可点击性不变）→ 快速入口宫格（6 项图标卡）→ 分组信息区（ghost Collapse：基本信息展开+四配置面板折叠）
- 拆 3 个纯展示组件（hero-header/stats-row/quick-entry-grid），page.tsx 降为编排层（450-480 行）
- 测试同步改写 + 新增统计/入口断言

## 不在范围内（显式清单）

- 不动 20 个子模块页面
- 不改业务逻辑/API/数据流，不新增 API 调用（hero 不放重新扫描）
- 不做移动端专项
- 不加新后端接口

## 成功标准（可验证）

- 九块→四段映射表 10 行逐块落地无遗漏（design §5 映射表对账）
- 统计四数字/6 入口链接与重构前等价（新增断言锁定）
- 既有 6 个 WorkspaceConfigCard 相关断言经 forceRender 策略全绿；全量 pnpm test 通过
- tsc/eslint 0 error；Docker rebuild 后双主题截图核对（横幅渐变 blue 侧平移）
