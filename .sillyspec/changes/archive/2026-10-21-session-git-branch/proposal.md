# 提案书（Proposal）— 2026-10-21-session-git-branch

## 动机

任务原话转写：会话组件底部动态显示当前所在 git 分支

动机与背景：工作区会话页顶部的 GitStatusBar 展示的是 workspace 根目录的 git 状态（60s 缓存、无轮询），既不是会话所在 worktree 的分支，也不保证动态。用户要求在会话组件内部（底部「智能体档案」控件后面）展示该会话当前所在分支或 worktree，且必须动态反映实时分支（会话运行中可能切分支）。

实现方向：后端新增会话级 git 状态端点（取 AgentSession.cwd，经既有 daemon RPC git_status 实时查询）；前端 SessionConfigBar 在「智能体档案」后新增分支展示项，轮询刷新。

成功标准：
- 会话组件底部「智能体档案」后面展示该会话当前所在 git 分支
- 分支信息为实时查询（非创建时快照）：会话运行期间分支变化后，展示随之更新（轮询刷新）
- 无 git 仓库/无 cwd 的会话有优雅降级展示，不报错
- 工作区顶部既有 GitStatusBar 行为不变

## 变更范围
