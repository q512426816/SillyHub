# 需求规格（Requirements）

## 角色
| 角色 | 说明 |
|---|---|
| 会话用户 | 在桌面/移动端使用智能体会话与群聊的平台成员（须为群成员才见群） |

## 功能需求

### FR-1: 预会话草稿按入口隔离（草稿串台修复）
Given 用户在入口 P1（工作区 W1 + 机器 R1）的预会话输入框输入内容未发送
When 用户返回列表后从另一入口 P2（工作区 W2 或机器 R2）新建预会话
Then P2 输入框为空（或 P2 自有历史草稿），P1 的内容不出现在 P2；同一入口重进仍恢复 P1 草稿
And 真会话草稿隔离零回归：会话 A 输入未发送 → 切会话 B 显示 B 自有草稿 → 切回 A 恢复 A 草稿（测试锁定）

### FR-2: 输入框高度拖拽触摸可用（拖拽修复）
Given 移动端（触摸屏）会话输入框或群聊输入框
When 用户按住输入胶囊上缘拖拽手柄竖向拖动
Then 输入框高度实时增减，钳制在 44-480px（且 ≤ 视口 60%）；松手高度持久化（刷新后保持）；双击手柄恢复默认高度
And 桌面鼠标拖拽/双击行为零回归

### FR-3: 群聊跨工作区可见（可见性修复）
Given 群 G 直接归属工作区 D、关联项目 A，项目 A 关联工作区 D 与 F，当前用户是 G 的成员
When 用户分别在工作区 D 与工作区 F 打开会话列表（桌面左栏 / 移动端列表页）
Then 两处的群聊分区均显示群 G
And 非群成员在 D 与 F 均不可见群 G（成员过滤前置不变）；打开群 G 后的访问控制与权限行为零变化；无 project 的群仅在其直接 workspace_id 可见；前端旧缓存（无新字段）过滤行为退化为现状（不闪隐）

## 非功能需求
- 兼容性：Pointer Events 基线（2019+ 浏览器全绿）；后端字段纯增量旧客户端无感；Windows/Linux/macOS 行为一致（纯 Web 逻辑无平台分支）
- 性能：项目→工作区映射单条 IN 批量查询（无 N+1）；列表渲染零新增请求
- 数据：不做旧 `__pre__` 键迁移；localStorage 键格式变更不清理旧键
