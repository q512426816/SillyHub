# 提案书（Proposal）

## 动机

用户要求手机端变更中心与 PC 端页面功能保持一致。移动端 `/m/workspaces/[id]/changes`（列表）与 `/m/workspaces/[id]/changes/[cid]`（详情）由 2026-08-26 变更建立时按「核心版」裁剪，与 PC 端逐项比对存在 10 项功能缺口，手机用户看不到 PC 用户能看到的信息、用不了 PC 端的操作。

## 关键问题

1. **列表页信息与操作缺失**：无「重新扫描」入口（PC 唯一的页头操作）；卡片缺负责人、执行用量（耗时/token/次数/进行中）、活动停滞徽标、影响组件四类信息；无排序切换；不支持 `?tab=/?search=` 深链；快速修复 tab 缺状态/作者/空壳占位筛选（PC 均有）。
2. **详情页区块缺失**：无执行用量卡、最后信号、范围对账卡；无删除入口（PC 有危险按钮）；阶段步骤条不可点击筛选时间线（PC 可点联动）。
3. **一致性维护成本**：两端功能面持续漂移会让「手机可用性」随每次 PC 迭代退化；本次对齐后应回到「PC 新增功能同步评估移动端」的基线。

## 变更范围

- 移动列表页 5 项补齐 + MobileChangeCard 信息增强；
- 移动详情页 5 项补齐（三卡复用挂载、删除、阶段联动）；
- 桌面列表页仅 export 三个既有格式化 helper（不改逻辑）；
- 配套测试补齐。

## 不在范围内（显式清单）

- 不做任务看板与任务执行页移动端（维持桌面引导条，D-002@v1）；
- 不改后端 API / 表结构 / DTO；
- 不新建 /m/ 路由；
- 不改变更级会话门户 deep-link 兜底。

## 成功标准（可验证）

- 默认（未操作筛选/无新数据字段）请求参数与改造前逐字相同，桌面/移动共享缓存语义不变；
- 列表页可完成：重新扫描并看到统计反馈、按排序/阶段/聚焦/quicklog 状态·作者·占位筛选、?tab=quicklog&search=xx 深链直达；
- 卡片在有数据时呈现负责人/执行用量/活动徽标/影响组件，空值按省略/占位规则降级不破版式；
- 详情页呈现最后信号（有信号时）、用量卡、范围对账卡；授权用户可从 ⋯ 菜单删除变更并回到列表；点阶段节点时间线按阶段筛选、可清除；
- 相关测试文件全绿 + `pnpm exec tsc --noEmit` 0 错误。
