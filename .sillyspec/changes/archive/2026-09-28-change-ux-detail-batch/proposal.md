## 动机
<!-- MACHINE-DRAFT:proposal-motivation:702d7bed37cf2b5c57ad160f00814ed16ae01da52c68bf5a2510a2253625ed5b:begin 机器预填段——整段改写会被 flow done 拒收；确要修改：sillyspec flow amend-draft --change 2026-09-28-change-ux-detail-batch 留痕重锚 -->
任务原话转写：变更中心列表与详情页一批 UI 体验问题（用户实测反馈）：①列表行描述过长溢出覆盖右列状态与影响模块（basis-full flex 项缺 min-w-0，truncate 失效）；②详情页不显示变更描述；③平台同步处理区常驻占位过大，应收进按钮；④详情页轻量变更两段式说明文案冗长不需要；⑤沉淀资产折叠卡在侧栏窄列难用——应默认展开、移主栏、卡片固定高度滚动对齐；⑥智能体运行状态卡（当前阶段未配置智能体）对 thin 变更是纯噪音；⑦关联快速任务空态占位；⑧范围对账卡说明文案冗长。
成功标准：
- 列表行描述单行截断不再溢出覆盖右列/影响模块（min-w-0 修复），悬浮全文保留
- 详情页头部显示变更描述（单行截断+悬浮全文）
- 平台同步处理区收进工具条按钮（搜索/重置旁），点开抽屉承载原处理区；无绑定数据源时抽屉内中性提示
- 详情页轻量变更说明卡（协议 1/2、2/2 长文案）不再渲染；顶部轻量流程条保留
- 沉淀资产卡默认展开、移入主栏，各分组卡片固定高度（超出滚动）网格对齐
- 智能体运行状态卡自桌面详情页移除（组件与移动端用法保留）
- 关联快速任务卡无关联时不渲染（有数据才显示）
- 范围对账卡去头部说明副标题与降级双段说明，压缩为单行降级提示（归档指路保留）
- 相关前端测试更新通过，tsc/eslint 0 错
