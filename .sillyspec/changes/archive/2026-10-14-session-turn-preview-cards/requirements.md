# 需求规格（Requirements）

## 角色
| 角色 | 说明 |
|---|---|
| 会话用户 | 通过 /sessions 页查看与续写智能体会话的平台用户（含长会话回顾场景） |

## 功能需求

### FR-01: 未加载轮次消息流预览卡
Given 用户打开含未加载轮次的长会话（消息流窗口外存在历史轮，且 turn-outline 大纲可用）
When 消息流渲染
Then 每个未加载轮按大纲轮序原位渲染预览卡，卡内含轮号、状态标识、时间、提问摘要（最多 2 行）与答复摘要（有则显示，最多 2 行）；已加载轮渲染完整内容不变；预览卡与已加载块视觉可区分（虚线边框 + 品牌浅底）；不产生任何额外网络请求。

### FR-02: 预览卡点击原地展开
Given 消息流中存在预览卡
When 用户点击某预览卡（或其「展开完整对话」入口）
Then 系统按该轮 run_id 拉取整轮日志并原地替换预览卡为完整轮块（替换后同轮不得出现双块），随后 2.2 秒 ring 高亮反馈自清；展开过程不触发滚动定位；该轮已加载后保持完整形态不再缩回预览态（D-003）；已加载/在飞加载中的轮再次点击不重复发起请求。

### FR-03: 跳转附近预取
Given 用户通过左侧导航跳转到某个未加载轮次
When 该轮单轮直达加载成功
Then 系统按大纲序取其前后各 1 个未加载轮（若存在）后台异步拉取并原位补入消息流，不阻塞目标轮显示、不打扰当前视口滚动；预取遵循三重防重（已加载判重、在飞去重、零正文轮幂等标记）；预取失败静默，不弹错误。

### FR-04: 大纲缺失降级
Given turn-outline 大纲不可用（拉取失败 / 旧 daemon / 空会话）
When 消息流渲染
Then 页面降级为现状形态（仅显示已加载轮内容），不报错、不空白、不渲染残缺预览卡。

## 非功能需求
- 兼容性：TurnTimeline/TurnRow 新 prop 全部可选，dialog 模式与 /runtimes 弹窗不传时渲染行为与现状逐字节等价（零回归门）；颜色走 brand-* 语义阶随 html data-theme 双主题换肤，零硬编码色值；数百轮会话预览卡渲染引入 content-visibility 屏外跳过，滚动不掉帧量级与现状持平；性能不变量：打开会话请求数不增加（大纲本就拉取），预览卡零请求。
- 可用性：预览卡整卡可点（命中区≥40px 行高惯例）；键盘可达（button 语义 + aria-label 携带轮号/状态/摘要，对齐 turn-nav 既有 a11y 口径）。
