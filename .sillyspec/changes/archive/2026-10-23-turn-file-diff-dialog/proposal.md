# 提案书（Proposal）— 2026-10-23-turn-file-diff-dialog

## 动机

任务原话转写：轮次文件变更卡行点击弹窗显示变更内容（18字）

动机与背景：会话轮次结束的「N 个文件变更」卡只有文件路径和 +/− 行数统计，点击文件行无任何响应（turn-timeline 挂载面未传 onOpenFile），用户无法查看该文件本轮到底改了什么。数据面已具备：daemon 上报的轮快照有 baselineHead 与逐文件 numstat；本轮 Edit/Write 的 structuredPatch 已落 agent_run_logs（edit_patch 列，tool_use_id 与 tool_call 行可配对），前端有现成 DiffView 渲染原语（agent-log/tool-diff.tsx）与会话级单轮日志 API getAgentSessionLogs(sessionId,{runId})。本变更纯前端：点击文件行弹 shadcn Dialog，拉本轮日志配对 edit_patch 渲染 diff；无补丁内容的行（命令行归因/二进制/加载失败）弹窗如实说明，不伪造内容。

成功标准：
- 点击文件变更卡中的文件行，弹出模态弹窗显示该文件本轮的具体变更内容（diff 形式，带行号红删绿增）
- 同一文件多次编辑（改N次）在弹窗中按次展示多段 diff
- 命令行归因/二进制等无补丁内容的行，点击后弹窗如实说明无补丁原因，不显示伪造内容
- 未接 sessionId 的旧消费方（agent-replay-body 等）零回归：行不响应点击、不出弹窗
- 相关组件测试绿（纯映射配对逻辑 + 弹窗形态 + 挂载面接线）
