# 决策记录（Decisions）— 2026-10-30-provider-user-share

## D-001@v1: 设计期风险与放弃方案（底稿）
- 类型：process
- 状态：confirmed
- 答案：本方案最大的风险是「授权主体从 runtime 属主改为会话属主」可能改变存量共享守护进程会话的 provider 解析结果：此前 runtime 属主的会话级 provider 生效、会话属主的被静默拒绝；改为会话属主后，会话属主自己的 provider 会开始真正生效（更符合预期），但依赖旧行为的会话可能换用不同供应商。缓解：仅当会话属主有有效授权（自有或共享）时才注入，否则原样回落默认链（与今日一致）。第二个风险是用户名精确匹配带来的目标枚举（404 区分不存在/禁用）；已用统一 404 文案收敛，不返回用户列表。放弃的方案：给共享加独立密码/额度上限——超出本次范围；把共享项放进设置页只读区——用户要求「只能在会话页面选择」，直接不展示更简单且无越权入口。
