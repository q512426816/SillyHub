/admin/roles 新建弹窗 + 工作区权限选择优化 · 原型对比

现状:右侧抽屉(Drawer w-560) + 38 个 menu 默认全展开 → 垂直拉得很长。本次:① 新建改居中弹窗(Modal) ② 权限选择三方案对比,你看完定方向。
下方三个方案共用 Modal 外壳(标题栏 + Key/名称/描述),仅权限区交互不同。

方案 A:默认折叠 + 搜索 推荐 · 改动最小

+ menu 默认折叠(只展开有选中的),垂直长度大幅缩短;顶部搜索框按权限名/key 过滤,快速定位。

− 权限多时仍需滚动(但折叠后已可控);搜索结果跨 menu 时高亮所属。

方案 B:左树(section/menu)右权限面板 专业 · 改面大

+ 左侧树总览全部 menu(选中态一目了然),右侧只显当前 menu 权限;高度固定不拉长,类似 RBAC 穿梭框。

− 改动最大(重写 picker 布局);小屏(560 Modal)左右分栏偏挤;需点击切换 menu 看权限。

对比小结
· A 折叠+搜索:改动最小,复用现有 menu 卡片结构(只改默认折叠+加搜索),立刻解决"太长",推荐首选。
· B 左树右权:体验最专业、高度固定,但重写布局、560 Modal 分栏偏挤,适合权限极多(>50 menu)的后期。
· C tab:介于两者,按 section 隔离,但跨 section 操作要切 tab。
三方案共用:新建改 居中 Modal(替代右侧抽屉),Key/名称/描述字段不变,保存/取消底栏不变。
