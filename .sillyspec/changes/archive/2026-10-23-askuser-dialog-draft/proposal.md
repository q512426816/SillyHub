# 提案书（Proposal）— 2026-10-23-askuser-dialog-draft

## 动机

任务原话转写：AskUser 弹窗选项与输入互斥及作答草稿保留

用户报障（原话）：1. 勾选的内容及输入的内容单选情况项应该是互斥的，目前勾选之后也能输入，输入之后还能勾选不对；2. 用户选择的选项和输入的内容刷新页面或切换会话后就丢失了（没提交的时候），这个也应该要保留的，参考会话输入方案。

成功标准：
- 单选问题：选中某个选项后手动输入框禁用不可输入；手动输入非空时选项按钮禁用不可勾选；取消选择/清空输入后另一侧恢复可用
- 多选问题保持现状：可勾多项，且可与手动输入合并作答（用户明确「仅单选互斥」）
- 未提交的单选项勾选、多选项勾选与手动输入文本，刷新页面或切换会话再回到该提问时原样恢复（参考会话输入草稿 localStorage 方案）
- 提交成功 / 被他人回答（409）/ 提问卡移除后该提问的草稿清除，不残留到下一次新提问
- tsc --noEmit 零错；ask-user 卡片与 pending-dialog-dock 相关测试全绿（新增互斥与持久化行为用例）
