③ 凭证取用流程（任务启动时，方案A）

1
档案绑了供应商？ 否 → 跳到步骤 3
2
绑的供应商 属于当前执行用户？ 是 → 用绑的供应商；否 → 忽略绑定，继续
3
当前用户在 /settings 设了默认供应商？ 是 → 用默认；否 → 继续
4
用 daemon 机器本地配置（现有行为，零回归）

步骤 2 的"属于当前执行用户"= 方案A 安全校验：共享档案绑的供应商不对其他成员生效，自动回退，不泄露密钥。

• 绑定的供应商被删 → 字段自动置空 → 回退默认
• 档案不存任何 API Key（R-02 安全红线不变）
• 运行中会话热切换：本次不改，活动会话仍接收 /settings 切换推送（已知，记录不修）
