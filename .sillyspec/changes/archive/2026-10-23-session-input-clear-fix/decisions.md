# 决策记录（Decisions）— 2026-10-23-session-input-clear-fix

## D-001@v1: 设计期风险与放弃方案（底稿）
- 类型：process
- 状态：confirmed
- 答案：- 最大风险：立即清空后「失败窗口期」用户误以为发送成功。缓解：失败路径既有 errorMsg/notify 提示（不变），且文本自动恢复到输入框。可接受。 - 放弃方案 A「发送时输入框转禁用+spinner 等响应」：不解决切换会话后的草稿残留，且阻塞连续输入，体验更差。 - 放弃方案 B「卸载 cleanup 里清草稿」：卸载时无法区分「发送在途」与「用户主动切走（草稿应保留）」，语义不可判定，死路。 - 放弃方案 C「dialog 模式（session-panel-dialog.tsx）同步修」：用户报障场景为会话页面（page 模式）；dialog 无测试覆盖基础，本变更不扩面，遗留同构问题已知并记录。 - 预会话「不回读草稿」牺牲了「预会话写一半切走再回来继续」场景：与「新建=全新开始」预期冲突时取后者（用户报障明确）；真会话草稿不受影响。
