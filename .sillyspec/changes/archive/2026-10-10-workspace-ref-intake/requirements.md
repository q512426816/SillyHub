# 需求规格（Requirements）

## 角色
| 角色 | 说明 |
|---|---|
| 会话用户 | 在会话页（单聊/预会话/群聊）编辑待发消息、浏览工作区文件与预览的登录用户 |
| 智能体 | 接收消息正文的宿主 Agent，按引用标记（wid+path+行号）自行读取工作区文件 |

## 功能需求

### FR-01: 文件树右键添加引用
Given 会话页左栏处于「工作区文件」模式且中栏有输入区（真会话/预会话/群聊）
When 用户右键文件树中的文件或目录节点
Then 出现上下文菜单（单项）；点击「添加文件/目录到会话输入框」后，当前输入区光标处插入该节点的引用标签（输入区失焦时插入失焦前光标位）；空门户态（无输入区）时 toast 提示不可用

### FR-02: 引用标签编辑与路径绑定
Given 输入区已插入工作区引用标签
Then 标签显示名称（代码块为「名称:起始行-结束行」）；悬停显示类型 + 工作区 + 完整相对路径（代码块含行号）；右上 × 角标删该处一次出现；光标贴标签尾按退格一次整删标签；同一引用可重复插入；同名引用自动加序号 ·2（唯一化池为附件 token ∪ 工作区 token 并集，按完整显示基名分配——D-005）；删除附件 chip 只剥离附件类标签，不影响工作区引用标签

### FR-03: 类型角标
Given 输入区存在引用标签（附件或工作区）
Then 镜像层标签左上角显示 lucide 类型角标：文件 FileText / 目录 Folder / 代码块 Braces / 附件 Paperclip（D-001）；角标不改变标签文本宽度（逐字符对齐不破坏）

### FR-04: 预览区行号（前置）
Given 右侧预览列展示代码或纯文本文件
Then 内容按行显示行号；行号列不可被选中（选区锚点只落内容区）；.md/图片/PDF/二进制分支无行号且行为与现状一致

### FR-05: 选区右键添加代码块引用
Given 预览区为代码/纯文本文件且用户选中了若干行（选区非折叠且起止落在行元素内）
When 用户在选区内右键
Then 出现菜单「添加选中内容到会话输入框（名称:起始行-结束行）」，点击后光标处插入代码块引用标签；行号按选区起止行元素的文档实际位置计算（反向选区取 min-max，不按文本匹配）；无选区或选区不在行元素内时右键为浏览器默认菜单（D-006）

### FR-06: 发送置换
Given 待发正文含工作区引用标签
When 消息发送（含定时发送、团队直发、群聊）
Then 标签全部置换为 `[文件引用:wid|path]` / `[目录引用:wid|path]` / `[代码引用:wid|path|L起-L止]`（全部组装位覆盖——2026-10-10 实测 7 处，D-008@v2：锚定 substituteAttRefsForSend 每个调用点，实现前 grep 重盘）；映射不命中的孤儿标签原样保留；后端与 API 零改动（D-004）

### FR-07: 历史渲染与预览
Given 历史消息正文含三类引用标记
Then 渲染为可点击标签（类型图标 + 名称 + 行号）；点击经 fetchDownload(workspaceId, path) 打开 FilePreviewModal 预览；本变更前的历史消息与含 `[附件引用:…]` 的消息渲染不变

### FR-08: 三输入区一致
Given 单聊（session-input-bar）、预会话、群聊（group-chat-panel）任一输入区
Then FR-01/02/03/06 行为一致（同一槽位契约与置换接线）

## 非功能需求
- 兼容性：未插入引用时输入区/预览区/发送链路零视觉与行为差异；FilePreview 未传选区回调的消费方（explorer 页）行为不变；孤儿标签降级为纯文本
- 平台：Windows / Linux / macOS 行为一致（路径为 POSIX 相对路径展示，无盘符拼接）
- 性能：历史解析单次线性扫描 + 段级缓存（React.memo 既有口径），长正文无感知开销
- 主题：角标/标签/菜单取值走 brand 语义阶与主题 token，双主题（ai-native/dark/blue）正常换肤
