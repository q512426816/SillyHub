# 提案书（Proposal）— 2026-10-21-provider-set-default-ui

## 动机

任务原话转写：供应商页复活设为默认入口

动机与背景：会话未显式选供应商时默认落本机凭证，根因是 2026-08-20（ql-20260820-006）删除了 /settings/providers 的启动/停止（set-default）UI，而后端 set-default/unset-default 端点与 claim 注入链（用户默认供应商优先于本机）仍存活，仅缺 UI 入口。本变更把「设为默认」操作加回供应商列表，文案与档案侧统一（设为默认/取消默认）；设默认只影响新会话，不主动切换运行中会话。

成功标准：
- /settings/providers 供应商列表有「设为默认」操作，已设默认的行有明确默认标记，且有对称「取消默认」操作
- 调用既有后端 set-default/unset-default API，后端链路零改动（若核实后端 set_default 存在运行中会话即时下发行为，则一并收敛为仅影响新会话并在 tasks 记录）
- 会话未显式选供应商时注入用户默认供应商凭证，未设默认回落本机（既有 claim 链路，UI 加回即通）
- 新增/更新前端测试覆盖设默认交互与 API 封装

## 变更范围

1. /settings/providers 供应商列表有「设为默认」操作，已设默认的行有明确默认标记，且有对称「取消默认」操作
