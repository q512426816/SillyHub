# 需求：会话群聊

## 功能需求（FR）

### 群管理
- FR-01 建群：选工作空间 + 群名 + 邀请用户成员（多选）+ 配置 agent 成员（六要素表单，可多个）；群上限——agent 成员 ≤8、用户成员 ≤50（超限拒绝并提示）
- FR-02 成员管理：群主可加/移除用户成员、增/删/改 agent 成员六要素；移除 agent 成员时结束其影子会话并清理队列 pending 行 + 群内系统提示
- FR-03 群设置：群名、互@协作开关（默认开）、群背景摘要条数（默认 20）、护栏参数可调；解散群=结束群会话+全部影子会话
- FR-04 群列表：`GET /api/group-chats` 按成员过滤返回（群名/成员摘要 chips/最后消息/在线成员）；workspaces/[id]/sessions 页与全局 sessions 页均有群聊分区

### 消息与触发
- FR-05 群消息：成员发送消息 → 落群时间线（载体 run + user_input 行 + 发送者身份）；每条消息可带附件（复用现有附件机制）
- FR-06 @提及路由：`@昵称` 精确匹配群内 agent 成员（全/半角 @，昵称群内全局唯一含用户与 agent 共用命名空间）；`@全体`/`@all` 触发全部 agent 成员并行；未被 @ 的消息不触发任何 agent
- FR-07 影子会话：agent 成员首次被 @ 懒创建影子会话（六要素 → pinned runtime/cwd/provider/model/profile，机器授权走 grants 分支）；长驻复用现有 resume/恢复链路；忙轮排队（per 影子队列，满 5 提示）
- FR-08 群背景摘要：触发成员时注入"最近 N 条群消息（含用户消息与 agent 回复摘要，带身份标签）+ 当前消息"；单条截断 500 字
- FR-09 agent 回复投影：影子回复实时流回群时间线（带成员头像/昵称/引擎模型标签）；tool/thinking 不进群；刷新/重连回放与实时顺序一致（平铺全局 timestamp 排序）
- FR-10 agent 互@协作：群开关开启时，agent 回复最终文本中的 @昵称 触发对应成员（与用户 @ 同管线，注入标注来源成员）；护栏——同链同成员去重、协作链深度上限（默认 2）、每成员每分钟触发上限（默认 6）、不自我触发；关闭时 @ 为纯文本
- FR-11 配置热切换：群聊中随时改 agent 成员的模型/引擎/方案 → SESSION_SWITCH_CONFIG 下轮边界生效、独立记忆不变；改机器/工作区 → 影子重建+记忆重置（确认提示）

### 实时与前端
- FR-12 群 SSE：多成员同时在线订阅同一群时间线流；断线重连 resync 不丢不错序
- FR-13 typing 指示器：用户输入草稿流式提示（≤400 字、TTL 2.5s、不落库不进 AI 上下文）；agent 回复时自动"「昵称」正在输入…"
- FR-14 成员面板：用户成员（在线绿点/移除）+ agent 成员卡片（六要素展示/热切换入口/重置记忆）
- FR-15 @补全：输入 @ 弹出成员补全菜单（agent 成员 + 用户成员 + @全体），键盘/点击选择回填

## 非功能需求（NFR）

- NFR-01 隔离：agent 成员独立记忆/独立机器进程/独立工作区/独立工具边界（人格+工具白名单+allowed_roots 三层）；成员间仅通过群背景摘要（只读）互见
- NFR-02 兼容：单聊会话（kind='chat'）行为零改动；SSE envelope 新字段可选向后兼容；存量数据迁移无损（新列 nullable/default）
- NFR-03 安全：群读写仅限群成员（+workspace admin 兜底），非成员 404 不泄露存在性；agent 成员机器授权走 grants 分支（不照抄 worker 豁免）
- NFR-04 防环：互@护栏 Redis 载体（链去重集 TTL 30min + 滑动窗口限频），双 agent 不可无限互相触发
- NFR-05 跨平台：Windows/Linux/macOS 兼容（无平台特定路径/进程语义）

## 验收标准（关键）

- AC-01 两用户+两 agent 建群：A 用户 @agent1 提问 → agent1 流式回复（带身份）→ 刷新页面回放顺序与身份一致；B 用户未 @ 发消息无 agent 触发
- AC-02 @全体：两 agent 并行回复，各自独立记忆（agent2 后续被 @ 时摘要中可见 agent1 回复）
- AC-03 互@：@agent1 让它转交任务给 agent2 → agent1 回复含 @agent2 → agent2 被触发；关闭开关后同样的 @ 不触发
- AC-04 热切换：agent1 回复中途切换模型 → 当轮继续旧模型完成、下轮用新模型；记忆延续
- AC-05 权限：非群成员访问群消息/流/详情 404；workspace admin 可读
- AC-06 typing：两浏览器同看一群，一方输入另一方实时见"正在输入"；草稿不入库不进摘要
- AC-07 单聊回归：现有单聊/quick-chat/团队会话行为与测试全绿
