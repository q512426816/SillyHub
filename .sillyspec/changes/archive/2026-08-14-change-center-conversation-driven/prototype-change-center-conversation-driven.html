1. 新流程总览（模型翻转：会话是第一步，平台只展示）

① 用户发起会话工作区「会话」页与 agent 对话，提供需求上下文。怎么走流程平台不管，本地 agent 技能引导。
→
② agent 建/推进变更agent 在会话里跑本地 sillyspec 命令（claim / brainstorm / plan / execute…）。
→
③ daemon 增量同步spec-sync 推文件 + 显式标注涉及的变更目录（方案B）；旧 daemon 由后端按路径检测兜底。
→
④ 后端精确重扫描apply_ops 按标注/检测触发 scoped reparse → ux_changes 自动出现/更新。
→
⑤ 平台展示 + 审批变更中心看文件/进度；关键节点人工审批（只改状态，回会话继续）。
