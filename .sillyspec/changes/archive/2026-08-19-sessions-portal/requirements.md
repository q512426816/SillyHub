# 需求规格（Requirements）— 智能体会话总入口页面（/sessions）

## 角色

| 角色 | 说明 |
|---|---|
| 平台用户 | 在 /sessions 发起/继续/切换会话配置 |
| 运维视角用户 | 继续使用 /runtimes 机器管理与会话弹窗（并存，本变更不改其行为） |

## 功能需求

### FR-01: 新建会话四选择器联动
覆盖决策：D-005@v1, D-010@v1
Given 用户在 /sessions 点「新建会话」
Then 表单依次为：守护进程（必选，仅在线机器可选、离线置灰；默认=上次选择(localStorage)→最近会话的在线机器→最新心跳）、智能体（必选，所选机器在线 runtime、默认 Claude Code、非 claude/codex 置灰标「暂不支持会话」、切机器重置默认）、供应商（可选，「不指定（本机默认）」+ 用户供应商；不选=一律本机默认（D-013）；所选智能体非 Claude 引擎时锁定）、档案（可选，「不指定」+ 跨工作区可见档案，不做引擎过滤；Codex 智能体下选项标注「人格暂不支持」）
And 原「智能体提供方/智能体模型」控件不再出现（新页面）
When 提交
Then createSession 携带 runtime_id + agent_profile_id? + llm_provider_id?（不传 provider/model）

### FR-02: 会话列表（所有会话）
覆盖决策：D-003@v1, D-006@v1
Given 用户进入 /sessions
Then 左侧列出跨机器/智能体的全部会话（含已结束/失败），紧凑两行条目（状态点+标题+相对时间 / 机器+引擎+档案+供应商+轮数 chips，chips 读会话快照实时反映当前配置）
And 筛选：引擎胶囊 tab（全部/Claude/Codex）、状态下拉（全部/活跃/已结束）、机器多选、标题搜索（回车触发）
And 列表虚拟滚动 + 后端分页
When 点击会话
Then 右侧打开该会话：活跃会话可继续对话；所属机器离线 → 只读横幅 + 输入禁用

### FR-03: 未选供应商/档案零回归
Given 用户不选供应商和档案（或经 /runtimes 弹窗开会在话）
When 会话执行
Then 行为与现状一致：全局默认供应商配置注入、无人格、模型走既有覆盖链

### FR-04: 会话级配置生效
覆盖决策：D-011@v1, D-013@v1
Given 用户选了档案和/或供应商
When 会话执行
Then 档案只注入人格提示词（system_prompt，Claude）+ mcp/skill 透传，不派生引擎/模型/供应商；供应商优先级=会话选择 > 全局默认（不选=本机默认，压制档案绑定）；每轮 AgentRun 记录配置快照

### FR-05: 会话内配置热切换（样式 B）
覆盖决策：D-004@v2, D-007@v1, D-012@v1
Given 会话 active 且当前轮完成（idle）
When 用户点输入框下方配置控件条中「供应商/档案」并选择新值、发送消息
Then inject 携带新配置+prompt；后端建新 AgentRun（新快照）并下发 SESSION_SWITCH_CONFIG；daemon 在轮次边界 reload（关旧 query→新配置 driverOpts→resume 重载历史→喂 prompt）；会话不中断、历史无缝、其它会话不受影响
And 机器/智能体控件为纯展示：下拉展示可选项但整体置灰（跨机器标「二期」、跨引擎标「需开新会话」——每机每引擎唯一 runtime，无可切目标，D-004@v2）
Given 当前轮运行中
Then 四控件置灰 + 「本轮完成后解锁切换」提示

### FR-06: 切换合法性校验
Given 用户绕过前端以不匹配供应商（agent_kind 与引擎不符、非本人供应商）发起切换
When 后端 inject_session 校验
Then 返回 4xx 中文错误；会话状态不变（档案无引擎属性，无需引擎校验，D-013）

### FR-07: 每轮配置快照（历史不跟随）
覆盖决策：D-008@v1
Given 会话发生过配置切换
When 渲染消息流
Then 每条回复 who 行显示该轮生效配置（`档案 · 智能体 · 供应商`，未选如实显示「未指定/本机默认」），切换后旧消息保持原配置不变

### FR-08: 上下文用量 + 供应商额度
覆盖决策：D-009@v1
Given 会话面板
Then 输入框上方一行显示上下文用量环形进度（累计 usage/模型窗口，分母=供应商配置派生（1M 勾选→1000k）→模型默认常量表（200k）→无则只显示累计 token，D-014；<50% 蓝/50-80% 黄/≥80% 红；点击详情 `xx.x% · xxk / xxk`）
And 当前供应商有额度数据时显示额度胶囊（各窗口剩余% + 重置时间，点击详情）；无数据/本机默认 → 不显示
When 切换供应商
Then 额度胶囊跟随新供应商数据切换显示

## 非功能需求

- **兼容性**：新列 nullable；provider 入参保留（/runtimes 弹窗零回归）；未选配置零行为变化；daemon sessions.json 兼容旧格式。
- **性能**：会话列表后端分页+过滤；前端虚拟滚动；列表 snapshot 直显免逐会话查询。
- **可测试**：供应商优先级矩阵、切换校验、daemon reload resume、组件联动均有测试。
- **跨平台**：Windows/Linux/macOS（路径/WS 消息/无平台特定调用）。
- **类型同步**：DTO 具名化后 `pnpm gen:types`，api-types.ts + openapi.json 同变更提交（规则 20）。
