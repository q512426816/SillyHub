# 提案书（Proposal）

## 动机

轨迹视图已作为会话面板第三个顶层视图上线，但当前形态是 7 列网格 + 泳道 + 检查器：顶部区域随整页滚动消失，账本缺少定位手段（无搜索、无折叠），详情只能在一列里平铺。用户对照 dsh（deepseek-harness）的轨迹实现提出整体重做，要求顶部固定，并按参考实现补齐工具栏、卡片账本与多标签详情。

## 关键问题

1. **顶部不固定**：轨迹面板被包在会话外层滚动容器内，滚到后面看不到泳道和时间轴。
2. **定位效率低**：长会话（千行级）无法搜索、无法按轮次/调用折叠，也看不到每条记录的层级关系。
3. **详情不可扫读**：输入/输出/计时/元数据混在一列，缺标签分区；行内却堆了耗时/token/状态，信息层级倒置。

## 变更范围

- 轨迹视图改为「固定工具栏 + 固定时间线 + 唯一滚动账本 + 右侧详情」的布局。
- 新增工具栏（时长开关 / 轮次折叠 / 调用折叠 / 搜索）。
- 账本改为无表头两列紧凑行，支持轮次分组、子工具缩进、折叠摘要行。
- 详情改为按行类型分档的标签页（工具行：概述 / 参数 / 结果 / 计时），支持可调宽与窄屏抽屉。
- 展示层拆为组件族；`build-trajectory` 不动，`from-turn-views` 仅补工具行字段映射与行 id 稳定性（D-015）；三态入口与持久化沿用现状。
- 真码原型先行落盘，实施按原型对照搬组件。

## 不在范围内（显式清单）

- 不改后端 API、daemon 协议、OpenAPI、数据库 schema。
- 不新增工具定义 / 请求级用量数据；Schema 标签隐藏（D-007）。
- 不搬 dsh 中无数据支撑的 request / 系统提示词变更 / 逐请求用量行（D-006）。
- 不改三态入口、视图持久化与移动版外壳。
- 不引入虚拟化库（先沿用 content-visibility，实测不足再另立变更）。

## 成功标准（可验证）

- 轨迹视图滚动账本时，工具栏与时间线保持在面板顶部不动。
- 工具栏四项均可用：时长切换改变时间线条块布局；轮次/调用可全部展开/收起；搜索能过滤账本行。
- 账本行按「事件列 + 内容列」渲染，行内不出现耗时/token/状态文字；点击行可在右侧查看对应标签详情。
- 工具行详情恰好四个标签（概述 / 参数 / 结果 / 计时），其它行只有概述 + 原始内容；不出现 Schema 标签。
- 三主题下无硬编码颜色；空态、三态入口、移动端行为零回归。
- 新增用例全绿，既有轨迹/会话面板相关用例零回归，`tsc --noEmit` 退出 0。
