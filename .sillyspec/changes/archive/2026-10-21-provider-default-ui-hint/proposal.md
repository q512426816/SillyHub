# 提案书（Proposal）— 2026-10-21-provider-default-ui-hint

## 动机

任务原话转写：供应商未选态显示对齐用户默认供应商

动机与背景：变更 2026-10-21-provider-set-default-ui 恢复了用户默认供应商（claim 注入链已验证生效），但前端「未显式选供应商」的显示面仍固定文案「不指定（本机默认）」（预会话/会话配置栏/群聊成员卡/轮 timeline），用户设了默认后看到「本机默认」误以为没生效（实测已确认注入生效、纯显示滞后）。

成功标准：
- 已设默认供应商时，各「不指定」下拉项文案显示「不指定（默认：{默认供应商名}）」；未设默认保持「不指定（本机默认）」
- 会话轮 timeline 的未选供应商显示同样对齐（null 时显示默认供应商名，无默认保持本机默认）
- 无新增后端改动；前端测试覆盖文案分支
