画面② 发起任务时选择档案

用哪个智能体档案跑这个任务？
兜底链：任务带档案 → 工作区默认档案 → 平台默认档案（按 workspace.default_agent 选 Claude Code 默认 或 Codex 默认）。绝不因没绑档案而卡住任务。
▼ dispatch 解析（后端，用户不可见）
run 带 profile_id？
├─ 是 → 加载 profile：provider 偏好 + MCP/技能引用 + system_prompt
│ → placement 按 provider ∩ 在线 daemon 能力 选 daemon（provider-aware）
│ → profile 内容快照写进 lease.metadata 透传给 daemon
└─ 否 → 回退 workspace 默认 → 平台默认（按 provider 选预置档案，仍走原 member_runtime 路径）

配置三层取交集（安全边界）

层管什么allowed_roots（可写目录）
daemon（机器）物理沙箱上限（机器能写哪）
workspace（业务）ToolPolicy 数据策略 + lease_root业务范围
agent profile（人格）能力白名单只能收紧（取交集最严）
生效 = daemon ∩ workspace ∩ agent，三层任一收紧都以最严为准。agent 层永不放宽。
