# 提案书（Proposal）— 2026-10-23-file-card-agent-grouping

## 动机

任务原话转写：文件变更卡按AGENT编辑分组展示并修弹窗说明

动机与背景：用户反馈三点——①卡片混列本轮 agent 编辑（Edit/Write，有补丁可看）与命令行/并行会话改动（无补丁），.sillyspec 等 CLI 生成文件把 agent 编辑淹没，需分组：本轮 AGENT 编辑默认展示，命令行及其他收进按钮点击才展开，折叠头改双段标题「本轮AGENT N 个文件变更 +a −d | 总共 M 个文件变更 +A −D」（共享工作区提示照旧）；②已删除文件行不可点击无说明，应可点击弹窗如实说明本轮被删除；③弹窗对无补丁文件的说明断言「由命令行/脚本改动」过于武断且与「来自 agent 编辑日志」副标题矛盾，须改为如实表述（未来自本轮编辑工具，可能来自命令行/并行会话/其他进程）。

成功标准：
- 折叠头双段标题：本轮AGENT 段（tool 归因计数与行级合计）+ 总共段（全部文件计数与合计），共享工作区提示保持
- 展开区默认只列 agent 编辑行；命令行/其他变更收进按钮行，点击展开该区段
- 已删除文件行可点击，弹窗展示补丁或如实说明删除无补丁
- 无补丁弹窗说明改为如实表述，不再断言唯一原因；有补丁时副标题才提 agent 编辑日志
- 既有 notice/degraded/破折号语义不回归，触及面测试绿
