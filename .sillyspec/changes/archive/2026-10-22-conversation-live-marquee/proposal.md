# 提案书（Proposal）— 2026-10-22-conversation-live-marquee

## 动机

任务原话转写：动机：会话页「对话」tab 运行中时只有一行状态条，用户感知不到 agent 正在真实执行；希望在该轮末尾用单行横向跑马灯，把「进度」视图中的过程信息逐条滑过，营造持续运行感。

成功标准：
- 对话视图运行中轮次（pending/running/interrupting）末尾渲染单行横向跑马灯，展示思考/工具/子代理/文件/系统事件等过程信息，终态轮不渲染
- 事件按发生顺序逐条横向滑过；新事件实时入队，无新事件时循环播放最近事件，保持持续流动感
- 同一段的流式文本更新不重复刷屏：按段 id 去重，每段只入队一次（工具状态变化就地更新不新增）
- 「进度」「轨迹」视图与历史轮次渲染行为零变化；旧回退轮（segments undefined）不接入
- 现有主题下视觉协调，移动端不溢出，prefers-reduced-motion 下降级为静态展示最新一条
- 用户上滚离开底部或组件不可见时暂停轮播，回到底部恢复
- 新增纯函数与组件测试，相关测试通过；lint / typecheck 通过
