任务原话转写：动机：知识页命中统计对锚点做逐字精确比较，而 CLI 写进 hits 的锚点与平台按标题现算的 slug 存在 emoji 前缀、点号保留、短横折叠三类规则漂移，真实命中被判成"幽灵锚"——平台仓本地实测丢 3234 次命中（11.4%），5 个手册小节因此显示为"从未命中/死条目"。

成功标准：
- 命中锚点与条目锚点匹配改为「精确优先 + 归一化回退」，归一键=小写且仅保留 0-9a-z_ 与中文（丢 emoji/点号/短横/斜杠等符号）
- 归一化后出现多候选（歧义）时不猜测，仍按未命中处理（保守，绝不虚增覆盖）
- 覆盖率分子/死条目清单/使用率榜/文件级计数四项统一用解析后的锚点归属，页面四项数字互相自洽
- 平台仓本地真实数据实测：命中可归属率 87.4% → 98.7%（+3234 次），歧义锚点 0 个
- 新增单测覆盖：emoji 前缀、点号保留、短横折叠三类真实漂移样本各一条 + 精确优先 + 歧义保守共三态
- 既有知识模块测试零回归（基线 124 passed）
