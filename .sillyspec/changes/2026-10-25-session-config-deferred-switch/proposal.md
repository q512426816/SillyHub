# 提案书（Proposal）— 2026-10-25-session-config-deferred-switch

## 动机

任务原话转写：会话配置点选改暂存随下条消息生效
动机:会话页空闲时点选供应商/模型/档案/思考级别会立即发起后端切换请求(空 prompt 静默切换建切换轮),时间线立刻多出一个空轮次,干扰浏览。
方案:点选仅前端暂存并提示下次发送时生效;发送下一条消息时,暂存的供应商/模型/档案随 injectSession 请求一并生效,思考级别在发送时先调 thinking-level 端点生效;发送受理成功后清空暂存并刷新会话详情。运行中点选保持现状(后端忙轮排队,本轮结束后生效,不建轮)。

成功标准：
- 会话空闲态点选四个控件不发任何网络请求,时间线无新增轮次,控件显示暂存值并带待生效标识
- 发送消息后暂存的供应商/模型/档案随 injectSession 生效,思考级别经 thinking-level 端点生效,暂存清空且配置条显示新值
- 下拉中选择回当前生效值即取消该字段暂存
- 运行中点选行为与现状一致(忙轮排队,本轮结束后生效,不产生切换轮次)
- 会话已结束/机器离线时控件不可点(现状保持)
- 相关单测更新并通过(session-config-bar 点选断言改为暂存上抛)

5. 会话已结束/机器离线时控件不可点(现状保持)
