本方向不推翻现有架构：antd + Tailwind + 共享布局四件套（PageContainer / PageHeader / SectionCard / DataTable）全部保留，只替换 token 层并新增 AI 原生细节。

落地路径（评审通过后走 SillySpec 流程）
  1. Token 层替换tokens.ts 色板 + globals.css 语义变量 + antd ConfigProvider（colorPrimary / colorInfo / colorBgLayout / colorBorder 等）同步换为本方案数值，全站组件自动生效。
  2. Tailwind 映射更新tailwind.config.ts 的 colors / boxShadow / borderRadius 对齐新变量；grep 清理硬编码蓝色残留。
  3. 会话页 AI 原生细节流式输出光标、typing 指示样式、上下文引用卡片、建议指令胶囊——只动表现层，不改 SSE 数据流。
  4. 逐页核对工作区卡片 / PPM 表格 / 登录页 / 拓扑图按新 token 核对观感，tsc + eslint + Docker 实测截图验收。
