# 提案书（Proposal）— 会话页三分屏：会话 ⇄ 工作区文件浏览器

## 动机

用户在会话页对话时需要就近查看工作区文件内容，现状必须切到工作区详情「文件」tab、离开会话上下文。用户要求在会话页内直接切换到工作区文件目录（带返回），点文件在会话窗右侧再分一列展示内容，形成三栏（结构树/会话窗/文件内容）且三栏可自由调宽。

## 关键问题

1. **上下文割裂**：看文件要跳工作区 explorer 页，会话列表筛选/滚动状态可能丢失，回来后要重新定位。
2. **不能同屏**：边聊边看文件（「帮我看看这个文件」）需要两个窗口/页面来回切换。
3. **左栏宽度固定**：会话页左栏现状固定 320px，长标题/长文件名看不全，用户明确要三栏自由调宽。

## 变更范围

- SessionsPortal 左栏二模（会话列表 ⇄ 工作区文件树）：头部「📁」切换 + 文件模式「← 返回会话」。
- 右侧文件内容列：点文件才展开，FilePreview 只读预览（代码高亮/图片/Markdown/二进制/下载/全屏），「✕」关闭。
- 三栏拖拽调宽（复用 PanelResizer，localStorage 记忆）：左栏 240–560 默认 320、右列 320–860 默认 480。
- 工作区上下文：scope 入口恒本工作区；全局 /sessions 按选中点快照 selectedWorkspaceId（会话/群/预会话/深链），无上下文置灰提示。
- 新组件 `portal-file-panels.tsx`（两壳 + 宽度常量）+ `SessionListPanel` 可选 `headerExtra` 插槽 + portal 状态/布局接线 + 两层测试。

## 不在范围内（显式清单）

- 不做文件编辑/保存（explorer API 只读）。
- 不动后端/daemon/数据库/api-types（零接口变更）。
- 不改工作区详情「文件」tab 页。
- 不在 dialog 弹窗/悬浮会话宿主加文件浏览。
- 移动端 variant 不做三栏。

## 成功标准（可验证）

1. /workspaces/[id]/sessions 可切换到本工作区文件树并可返回；点文件右侧展开预览列可关闭。
2. /sessions 全局：选中带工作区的会话/群聊后可切换；未选中置灰 + title 提示；深链（含群）恢复后自动可点。
3. 切回会话列表预览列保留；重进文件模式树按最新工作区；预览按 {workspaceId, path} 不串档。
4. 左/右把手可拖宽、双击复位，刷新宽度记忆；中栏自动伸缩不破布局。
5. tsc/eslint 无新增问题；sessions-portal + portal-file-panels 测试全绿；既有 explorer 页测试零回归。
