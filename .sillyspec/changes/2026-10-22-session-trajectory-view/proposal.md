# 提案书（Proposal）— 2026-10-22-session-trajectory-view

## 动机

任务原话转写：会话页接入轨迹第三视图

轨迹档 1 目前只挂在 dev 路由 `/proto/session-trajectory`，产品会话页只有「对话 / 全部（进度）」两视图，用户在会话里看不到轨迹。本变更把轨迹接进产品会话页：数据复用页面已加载的轮/段视图，零后端改动、零新增网络请求。

> **形态修订（D-035，执行期用户裁决）**：不新增第三个视图模式。轨迹改为「进度」视图内部的呈现方式开关（时间线 / 轨迹），默认「时间线」＝现状逐字不变；同时把 `/runs` 已返回的 `timing`（daemon TTFT/attempt 采样）透传到轮视图，使模型泳道在可采样时按真实占用绘制、无采样时才标「近似」。原「第三个视图按钮」不再交付。

成功标准：
- 「进度」视图内出现「时间线 / 轨迹」呈现开关；默认「时间线」＝现状零变化；点「轨迹」渲染三泳道时间轴（输入 / 模型 / 工具）+ 共享轴 + 账本 + 检查器，轮块列表让位；「对话」视图不出现该开关
- 轨迹数据由当前会话已加载的 SessionTurnView[] 派生（零新增网络请求、零后端改动、零 API 变更）
- `/runs` 的 `timing` 透传到轮视图：有 attempts 采样 → 模型泳道标「真实占用」（`observed`）；无采样 → 标「近似」，不伪造
- 无可用时序数据时显示显式空态提示，不白屏、不伪造条
- tsc 退出 0；既有 trajectory 61 / turn-segment-views 93 / turn-time-display 8 / session-list-panel 119 例不回归，新增适配器与呈现开关用例全绿
